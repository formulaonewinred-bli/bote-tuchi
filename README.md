# ボートレース 直前通知（GitHub Actions 版）

PCの電源を切っていても、GitHub のサーバー上で自動で動き、条件を満たしたレースだけスマホに通知します。

## しくみ

1. **毎日 05:10**：公式の競走成績ファイルを取り込み、選手ごとの **逃げ率・逃し率**（直近180日）を更新（`stats`）
2. **07:07〜20:37 の30分おき**：監視を起動（`monitor`）。動いている実行があれば次は待機し、その日の未処理レースを締切前チェックの時刻順に処理します（処理済みは `state/` に記録）
   - 本日開催の全場から、**1号艇 逃げ率70%以上 かつ 2号艇 逃し率35%以上** のレースを探す
   - そのうち **優勝戦・準優勝戦（12Rのもの）・企画レース** のどれかに当たるもの（女子戦は除外）を対象にする
   - その日の最初の実行で、チェック対象一覧を通知
   - 各レースの **締切18分前** に公式サイトの直前情報とオッズを確認し、次を **すべて満たす場合だけ** 通知
     - スタート展示が枠なり（1-2-3-4-5-6）
     - 3連単の1番人気と2番人気が、どちらも **1-2-3・1-3-2・1-2-4** のどれか
     - 1番人気のオッズが **10倍未満**（1桁台）

条件はすべて `config.yaml` で変更できます。

## 的中まとめ

チェックしたレース（通知したもの・除外したもの）は `data/checks.csv` に記録され、翌朝、公式の競走成績から結果を取り込んで **[REPORT.md](REPORT.md)** に的中率・回収率をまとめます。除外したレースの「もし買っていたら」も出るので、条件の見直しに使えます。

## はじめにやること（1回だけ）

### 1. 通知アプリ「ntfy」を入れる
1. スマホに **ntfy** アプリを入れる（iPhone: App Store／Android: Google Play、無料・登録不要）
2. アプリで「＋」→ トピック名を入力して購読（Subscribe）
   - トピック名は**他人に推測されない長い文字列**にしてください（例：`boat-kawatsu-7f3k9q2xw8`）。知っている人は誰でも通知を読めます。

### 2. GitHub にリポジトリを作ってファイルを置く
1. GitHub で新しいリポジトリを作成（**Public** にしてください。Private だと無料枠の実行時間が足りません。コードが公開されるだけで、通知先は次の手順で秘密にします）
2. このフォルダの中身をすべてアップロード（`.github` フォルダも含めて）

### 3. 通知先を秘密情報として登録
リポジトリの **Settings → Secrets and variables → Actions → New repository secret**
- Name: `NTFY_TOPIC`
- Secret: 手順1で決めたトピック名

### 4. 逃げ率・逃し率のデータを作る（初回のみ）
**Actions → stats → Run workflow**（日数は 180 のまま）。数分〜10分ほどで `data/course12.csv` が作られます。

### 5. 動作確認
**Actions → monitor → Run workflow** で mode を選んで実行：
- `test-notify`：通知が届くか確認
- `test-past`：昨日（または指定日）のレースで判定を試し、結果を1通にまとめて通知
- `dryrun-today`：今日のチェック対象一覧を通知

ここまでできれば、あとは毎日自動で動きます。

## 注意
- GitHub の定期実行は混雑時に数分〜数時間遅れることがあります。30分おきに起動を試み、起動した時点で未処理のレースをすべて担当するので、遅れても締切に間に合うレースはチェックされます。締切チェック自体は実行中のプログラムが時刻を待って行います。
- 逃げ率・逃し率は公式の競走成績から自前で計算しているため、ボートレース日和の表示とは少し異なります。集計期間は `stats_days` で変更できます。
- 公式サイトへのアクセスは1レースあたり数回、間隔をあけて行います。公式サイトの利用規約はご自身でもご確認ください。
- 企画レースの一覧（`config.yaml` の `kikaku`）は、マクールの一覧が変わったら手で更新してください。
- リポジトリに60日間動きがないと GitHub が定期実行を止めますが、`stats` が毎日データを更新するので通常は止まりません。
